## Description

Fourth episode of the pipe sorting series. Only 5 pipes this time. I've decided to switch to shorter videos with fewer pipes as the 10-pipe format was getting too long. I also refine the numbering system further, adding a pipe-order number within each video to create a fully unique ID for each pipe. The rating system is also lightly updated: "estimated value" is reworded to "rating" to better reflect that it measures how much others might want the pipe rather than its actual monetary worth. All five pipes in this episode are Mr. Brog pipes from the Polish batch. A brand I believe is Polish. None of them appear to be briar, possibly cherry wood (pear wood actually) or another material. A recurring issue across the batch is cracking, likely from the non-briar wood being more susceptible to heat damage.
